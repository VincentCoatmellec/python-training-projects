# FX Converter

A simple currency converter with a graphical user interface built with PySide6.

## Description

This project is an introduction to graphical interfaces in Python using PySide6. It applies concepts learned during the training such as classes, functions, and variables in a GUI context.

---

## Features

- Convert an amount from one currency to another
- Invert currencies with a single click
- Real-time result update

---

## Requirements

- Python 3.13
- Install dependencies from `requirements.txt`

---

## How to Run It

1. **Navigate to the project directory**:
```bash
cd project_11_fx_converter
```

2. **Create and activate a virtual environment** (recommended):
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: `venv\Scripts\activate`
```

3. **Install dependencies**:
```bash
pip install -r requirements.txt
```

4. **Run the program**:
```bash
python3 app/app.py
```
